Editar o jogo

Arquivo JSON

Ao importar, o jogo atual será substituído. O JSON exporta as peças, não as escolhas realizadas.

Como deve ser o formato do JSON?

Use o botão “Baixar JSON” como modelo. Cada lista dentro de opcoes pertence ao jogador na mesma posição em jogadores; cada peça corresponde aos números 1, 2 e 3.

{
  "titulo": "X1 da Sorte",
  "jogadores": ["Rodrigo", "Marcos"],
  "rodadas": [{
    "categoria": "Processadores",
    "opcoes": [
      [{"peca":"Ryzen 7 9800X3D","nivel":"Bom"},
       {"peca":"Intel i3-2100","nivel":"Ruim"},
       {"peca":"Intel i5-10400F","nivel":"Mediano"}],
      [{"peca":"Intel i5-750","nivel":"Ruim"},
       {"peca":"Ryzen 5 5600X","nivel":"Mediano"},
       {"peca":"Ryzen 9 9950X3D","nivel":"Bom"}]
    ]
  }]
}
